# Changelog

## 0.1.0 — 2026-10-04

Initial experimental, source-only release derived from the local temporary style prototype.

- Prominent Chinese/English credit to Fei-Away/Codex-Dream-Skin, with the independent temporary-tool relationship explained.
- Only apply and remove commands.
- No preview page, preview builder, browser entry, manager window, app launcher, watcher, startup task or automatic restart.
- No machine-specific runtime path, private profile, saved session or downloaded theme artwork.
- Explicit consent for applying to a manually prepared loopback session.
- Registered Store package, fixed endpoint, profile path, process identity and unique main-process checks.
- Owned stylesheet, visible-chat selection, geometry protection, bounded waits and rollback.
- A 45-second CLI deadline, public packaging allowlist, Chinese/English documentation and MIT license.
- Explicit app-open/app-closed and image-preparation instructions, standalone terminal steps, guarded manual preparation, and troubleshooting/recovery guidance.
- A 3-second image loading check before changing styles, with refusal on undecodable images or a page change; four added offline failure cases.

The reduced transport and command entry have not been retested with a live Codex window. Compatibility and full exit recovery require a separate manual acceptance test.
